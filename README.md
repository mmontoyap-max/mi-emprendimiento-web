# Manos Talentosas — Sitio web

Sitio web académico de venta de rosas eternas desarrollado únicamente con HTML5 y CSS3.

## Estructura

- `index.html` — Página de inicio.
- `nosotros.html` — Historia, misión, visión, valores y equipo.
- `productos.html` — Catálogo con seis productos.
- `contacto.html` — Datos de contacto, formulario visual y mapa ilustrativo.
- `assets/css/style.css` — Hoja de estilos.
- `assets/img/logo.png` — Logotipo proporcionado para la marca.
- `assets/img/banner.jpg` — Banner proporcionado para la página de inicio.
- `assets/img/` — Imágenes locales para el catálogo.

## Tecnologías

- HTML5 semántico.
- CSS3.
- Flexbox y CSS Grid.
- Media queries para diseño responsive.
- Pseudoclases `:hover` y `:focus`.
- Sin JavaScript, React, Bootstrap, WordPress ni constructores visuales.

## Personalización

En `contacto.html` y en los pies de página reemplaza:
- `[Tu dirección / ciudad]`
- `[Tu número de teléfono]`
- `[tucorreo@ejemplo.com]`

El formulario es únicamente visual y no procesa envíos porque el proyecto funciona solo con HTML y CSS.

## Cómo abrir

Abre `index.html` en cualquier navegador web. Los enlaces entre las cuatro páginas funcionan mediante rutas relativas.
